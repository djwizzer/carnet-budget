# Carnet de budget

Petite appli web de budget, installable sur Android.

- Importe un relevé bancaire **PDF** (téléchargé depuis ta banque).
- Les opérations sont extraites et classées automatiquement par catégorie.
- Résumé du mois : revenus, dépenses, reste, répartition par catégorie.
- Budgets mensuels par catégorie, avec alerte quand tu approches ou dépasses la limite.
- Les corrections de catégorie sont retenues pour les prochaines opérations du même commerçant.

Toutes les données restent dans le navigateur du téléphone (localStorage). Rien n'est envoyé sur un serveur.

## Installer sur Android
Ouvre le site dans Chrome → menu ⋮ → **Installer l'application** (ou **Ajouter à l'écran d'accueil**).
